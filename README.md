# Circular Economy Marketplace – Landing Page

High-impact, modern landing page for a sustainability tech startup. Built with React (Vite) and Tailwind CSS.

## Get started

1. Install dependencies
```bash
npm i
```
2. Run the dev server
```bash
npm run dev
```
3. Open the URL printed in the terminal.

## Tech
- React 18 + Vite 5
- Tailwind CSS 3 + Typography plugin

## Structure
- `src/App.jsx` – page layout and sections
- `src/components/*` – UI sections and Navbar
- `src/data/mock.js` – mock content
- `src/hooks/useReveal.js` – simple intersection observer for reveal animations
- `src/index.css` – Tailwind and utility classes

## Notes
- All content uses mock data and can be replaced with live API later.
- Fully responsive with hover effects and smooth scroll.
